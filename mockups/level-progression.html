Level Progression — Playable Prototype

Every level below is wired to a faithful port of this project's real ChainEngine.js — the same drag/step/backtrack/lock rules the shipped game uses. Tap any card to actually play it: drag from an anchor, retrace your own tail to undo, and lock every chain to win. Number Code uses a single chain per level (matching the real "mật mã số" levels) — the Super Hard one has only 2 checkpoints but a 24-of-25-cell path, verified solvable, not just illustrated.

Drag from a colored circle. Drag back over your own trail to undo. A chain locks once it fills its full length (and — for Number Code — ends on the last numbered stop).
